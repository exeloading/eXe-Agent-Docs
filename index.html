How it works

Every job runs the same five steps

Small, clear changes you ask for run directly and are still read back. Larger work, deletes and Python scripts wait for your approval of an exact plan.

  1. Ask

    Describe the task in your own words, in the eXe chat or in a connected AI client.

  2. Plan

    eXe prepares a plan with exact targets: what may change and what must not change.

  3. Approve

    You approve the plan in the chat or ask for a revision. Nothing in it is written before that.

  4. Execute

    eXe edits, saves, compiles and repairs failed steps, but only inside the approved scope.

  5. Verify

    eXe reads the result back from the editor and ends the job with a clear result level.

What it works on

From Blueprints to builds, in the project you have open

eXe reads Blueprints, C++, assets, levels and settings, and changes them through Unreal's own editor tools.

Blueprints

Variables, default values, components, functions with parameters and graph nodes. Compile, save and read back.

C++

Create and edit classes and source files, Live Coding or a full build with Unreal Build Tool. Needs Power Write.

Assets and materials

Create, rename, move and import assets. Materials, material instances and parameters.

Levels and world

Place, move and configure actors, blockouts, landscape, foliage and PCG.

UMG and animation

Widget Blueprints and texts, Animation Blueprints, montages, sequences and skeletons.

Gameplay, audio and VFX

Enhanced Input, Gameplay Tags, State Trees, Behavior Trees, MetaSounds and Niagara.

Play in Editor tests

Game runs with input, log and state checks and a screenshot after game steps.

Logs and errors

Reads the output log and build results and fixes the cause inside an approved plan.

7 interface languages

English, German, Spanish, French, Japanese, Korean and Simplified Chinese. Replies in the language you choose.

You stay in control

Approve what changes, and undo it

  • Plan before changes. Automatic, Only when I ask or Always. With Always, every change waits for your approval.
  • Changes list with revert. Every finished job lists the files and assets it changed, with diff, keep and revert. eXe keeps a copy for 14 days.
  • Power Write and YOLO start off. C++ changes and Python scripts need Power Write. YOLO, which approves plans for you, stays off until you turn it on.
  • Stop at any time. Stop a reply in the chat or end a job in Jobs. Finished steps stay listed for review.

Every job ends with a result level

Goal verifiedeXe read fresh values back from the editor, and they meet the goal of the plan.
Goal not independently verifiedReported as reached, but eXe could not confirm it itself, for example a visual change.
Change provenThe change itself is proven, the overall goal is not.
FailureA step failed, and the job shows the reason.

eXe never shows a higher level than its checks support.

FAQ

Common questions

More answers in the full FAQ, and every message eXe shows in Troubleshooting.

Do I need an API key?

Not necessarily. You can use your own API key, a local model on your PC, or Claude Code, Codex or Claude Desktop with your own login. The Tools view works without any AI.

Is my ChatGPT Plus or Claude Pro subscription an API key?

No. A chat subscription and API access are separate products. With your Claude or ChatGPT login you can use Claude Code, Codex or Claude Desktop instead.

What does it cost?

You pay the plugin price on Fab once. There is no eXe subscription. AI use is billed by the provider you connect, under your own account.

Does eXe send my project to your servers?

No. There are no eXe servers, no eXe account and no telemetry. Your messages and the project data the AI requests go only to the AI provider you choose.

Will eXe change my project without asking?

Only small, clear changes you ask for run directly. Larger work, deletes and Python scripts wait for your approval. Every change is listed and can be reverted. Use version control as well.

Does it work with Blueprint-only projects?

Yes. Blueprint, asset, level, material and UMG work needs no C++ and no build.

Can eXe change C++ code?

Yes, after you turn on Power Write. eXe uses Live Coding for changes inside existing .cpp files where it can, otherwise a full build with Unreal Build Tool from your own Engine.

How is eXe different from Epic's Unreal Assistant in 5.9?

Epic's Unreal Assistant is an Experimental panel in the Unreal Engine 5.9 Preview; the final 5.9 is expected in 2027. eXe runs on Unreal Engine 5.8 and adds its own plan with exact targets that waits for your approval, a read-back check with a result level for every job, and revert per file or job. Will eXe Agent support Unreal Engine 5.9?

Yes, support for Unreal Engine 5.9 is planned as a free update after Epic releases 5.9 and Fab accepts it.
